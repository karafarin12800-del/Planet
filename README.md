# PLANET — شبیه‌ساز سیاره

نسخهٔ اولیهٔ شبیه‌سازی تعاملی زمین و منظومهٔ شمسی؛ با WebGL خام و بدون کتابخانهٔ جاوااسکریپت خارجی. برای اجرا فقط `index.html` را در مرورگر جدید (Chrome، Edge یا Firefox) باز کنید.

## امکانات فعلی
- کرهٔ سه‌بعدی زمین با بافت رویه‌ای آفلاین و تلاش اختیاری برای بارگذاری نقشهٔ سطح و ابرهای واقعی‌تر از مخزن عمومی Three.js؛ اگر اینترنت در دسترس نباشد، بافت مولد جایگزین باقی می‌ماند.
- چرخش زمین در چرخهٔ ۲۴۰ ثانیه‌ای: نیم‌چرخهٔ روشنایی ۱۲۰ ثانیه و نیم‌چرخهٔ تاریکی ۱۲۰ ثانیه.
- نمای منظومه با خورشید و عطارد، زهره، زمین، مریخ، مشتری و زحل؛ دوره‌های مداری نسبی آن‌ها بر پایهٔ مقادیر مرجع نجومی.
- سرعت مداری قابل‌تنظیم، مکث/ادامه، چرخاندن دوربین، زوم، نمایش/پنهان‌سازی ابر، جو، مدار و ستاره‌ها.
- داشبورد ترکیب جو، فشار، دما، پوشش ابر و یک مدل نمایشی از تغییر جمعیت میکروبی.
- سازگار با صفحهٔ موبایل و رایانه.

## نکتهٔ علمی و محدودیت‌ها
این نسخه نمونهٔ بصری/آموزشی است، نه مدل اقلیمی یا اخترفیزیکی دقیق. بدون اینترنت، نقشهٔ زمین به‌صورت رویه‌ای تولید می‌شود و مرز قاره‌ها تقریبی‌اند. در صورت دسترسی به اینترنت، برنامه تلاش می‌کند بافت زمین و ابرهای نمونهٔ عمومیِ پروژهٔ Three.js را از نشانی‌های خام GitHub بارگذاری کند؛ این بافت‌ها برای نمایش آموزشی‌اند و ادعای کالیبراسیون یا دقت اندازه‌گیری ناسا ندارند. برای استفادهٔ نهاییِ عمومی، مجوز دقیق و انتساب منابع بافت‌ها را قبل از انتشار بررسی کنید. مقادیر فشار و ترکیب جو و برخی پارامترهای محیطی مرجع‌اند؛ دما، ابر و زیست‌کره در این نسخه به‌صورت نمایشی/ساده‌سازی‌شده مدل می‌شوند. میکروارگانیسم‌ها واقعی نیستند و تنها جمعیت ریاضی‌اند.

سرعت چرخش روز/شب مستقل از سرعت مدار تنظیم شده تا روز و شب همیشه هرکدام ۲ دقیقه باشند؛ در نتیجه وقتی سرعت مدار ×60 یا ×365 است، زمان‌بندی کل منظومه فیزیکیِ هم‌مقیاس با چرخهٔ روز/شب نیست. سرعت ×1 برای نسبت زمانی نزدیک‌تر به واقعیت استفاده شود.

## GitHub Pages
مخزن را با نام `Planet` بسازید، محتویات این پوشه را در شاخهٔ `main` قرار دهید، سپس در Settings → Pages، گزینهٔ Deploy from a branch، شاخهٔ `main` و پوشهٔ `/ (root)` را انتخاب کنید. پس از انتشار، آدرس سایت معمولاً `https://<username>.github.io/Planet/` خواهد بود.
