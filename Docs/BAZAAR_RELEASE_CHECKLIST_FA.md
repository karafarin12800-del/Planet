# چک‌لیست نهایی انتشار Planet Genome در کافه‌بازار

این چک‌لیست برای آماده‌سازی نسخهٔ 1.0.0 است. هیچ موردی را «انجام‌شده» تلقی نکنید مگر آن‌که عملاً تأیید شده باشد.

## ۱) بستهٔ اندروید
- [ ] آخرین commit شاخهٔ main را با موفقیت در Android workflow بسازید.
- [ ] خروجی APK را روی گوشی واقعی نصب و آزمایش کنید.
- [ ] بازشدن برنامه، جابه‌جایی میان صفحه‌ها، چرخش/تغییر اندازه، زبان فارسی و انگلیسی، کنترل شبیه‌سازی و رفتار در حالت قطع اینترنت را بررسی کنید.
- [ ] مجوزهای بسته را بررسی کنید؛ manifest فعلی فقط INTERNET را صریحاً درخواست می‌کند.
- [ ] برای انتشار، APK یا AAB امضاشده و سازگار با قالب پذیرفته‌شده در پیشخان انتخاب کنید. فایل دارای برچسب UNSIGNED برای انتشار نهایی مناسب نیست.
- [ ] کلید امضای انتشار و رمزهای آن را خارج از مخزن عمومی و در محل امن نگه دارید. هرگز آن‌ها را در GitHub یا فایل‌های پروژه commit نکنید.
- [ ] برای به‌روزرسانی بعدی، versionCode را افزایش دهید و از همان کلید امضای انتشار استفاده کنید.

## ۲) صفحهٔ فروشگاه
- [ ] نام: Planet Genome: شبیه‌ساز حیات
- [ ] توضیح کوتاه و کامل فارسی را از این فایل بردارید: Docs/BAZAAR_LISTING_FA.md
- [ ] توضیحات انگلیسی را در صورت نیاز وارد کنید.
- [ ] آیکون نهایی را با اندازه و قالب مورد درخواست فعلی پیشخان بارگذاری کنید.
- [ ] اسکرین‌شات‌ها را از نسخهٔ واقعی و اجراشدهٔ برنامه تهیه کنید؛ تصویر تبلیغاتی یا تولیدشده را به‌جای تصویر واقعی رابط کاربری معرفی نکنید.
- [ ] حداقل این نماها را ثبت کنید: کرهٔ زمین، داشبورد/کنترل شبیه‌سازی، ژنوم و آمار توالی، زیستگاه/موجود دیجیتال، آزمایشگاه کیهان‌شناسی.
- [ ] رده‌بندی سنی، دسته، اطلاعات پشتیبانی و سایر فرم‌های لازم را در پیشخان تکمیل کنید.

## ۳) حریم خصوصی و ادعاهای علمی
- [ ] صفحهٔ حریم خصوصی را در یک نشانی عمومی HTTPS باز کنید و از دسترسی بدون ورود به حساب مطمئن شوید: https://github.com/karafarin12800-del/Planet/blob/main/privacy.html
- [ ] اگر از GitHub Pages استفاده می‌شود، نشانی نهایی منتشرشده را جداگانه آزمایش کنید؛ وجود فایل در مخزن به‌تنهایی دسترسی صفحهٔ میزبانی‌شده را تضمین نمی‌کند.
- [ ] توضیحات فروشگاه با رفتار واقعی برنامه و سیاست حریم خصوصی مطابقت داشته باشد.
- [ ] حیات دیجیتال را شبیه‌سازی آموزشی معرفی کنید، نه پیش‌بینی علمی تأییدشدهٔ فنوتیپ واقعی از ژنوم کامل.
- [ ] دربارهٔ داده‌های رصدی کیهان‌شناسی ادعای اجرای تحلیل آماری رسمی یا برازش مستقل مدل‌ها نکنید، مگر واقعاً پیاده‌سازی و اعتبارسنجی شده باشد.

## ۴) ارسال و انتشار
- [ ] در پیشخان، برنامهٔ جدید/رهانش را ایجاد و شناسهٔ بستهٔ com.planet.live را کنترل کنید.
- [ ] نسخه و فایل امضاشده را بارگذاری کنید.
- [ ] پیش‌نمایش صفحهٔ فروشگاه را در موبایل بررسی کنید.
- [ ] درخواست بررسی را ارسال کنید و وضعیت آن را از داخل پیشخان پیگیری کنید.
- [ ] فقط پس از تأیید پیشخان، برنامه را منتشرشده اعلام کنید.

- versionName: 1.0.0
- versionCode: 1
- minSdk: 23 (Android 6.0)
